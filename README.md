# Sufiyan — Photography Portfolio

> *"Observing quiet narratives, fleeting light, and human presence."*

A minimal, high-performance portfolio website built for photographer **Sufiyan** ([@shaan.shoot](https://instagram.com/shaan.shoot)).

## ✨ Features
- **Editorial Aesthetic**: Curated dark palette (`#0B0B0C`), typography pairing *Instrument Serif*, *Inter*, and *DM Mono*.
- **Archival Works**: Complete 73-photograph collection across Portraits, Events, Street, and Travel.
- **Dynamic Interactions**:
  - GSAP-powered parallax hero and smooth scroll transitions
  - Interactive category filter toolbar with smooth layout reflow
  - Fullscreen Lightbox modal with keyboard navigation (`ArrowLeft`, `ArrowRight`, `Esc`) and touch swipe
  - Custom fluid brass cursor
  - Fully responsive across mobile, tablet, and ultra-wide displays
- **Performance & Accessibility**:
  - Strict performance optimizations with preloaded high-priority hero assets
  - Full support for `prefers-reduced-motion`

## 🛠️ Tech Stack
- **Framework**: [React](https://react.dev/) + [Vite](https://vite.dev/)
- **Animation**: [GSAP](https://greensock.com/gsap/) (ScrollTrigger)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Typography**: Instrument Serif, Inter, DM Mono (Google Fonts)

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
